Before you begin

Good questions. Clear answers.

Can I use it without registration?

Yes. A personal list is available locally. Connect shared access when you want to use it together.

How do I invite someone?

Create an invitation link in Home. A new participant sends a join request for the owner to approve.

Does a shared list work offline?

Saved information remains available locally. Syncing changes between participants requires an internet connection.
