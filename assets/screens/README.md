# Скриншоты приложений из RuStore

Актуальная проверка: 27 октября 2026 года. 40 кадров для семи приложений.
Полные ссылки на карточки RuStore, исходные изображения, размеры, размеры файлов
и версии локальных ресурсов находятся в `manifest.json`.

- Исходное разрешение и прозрачность сохраняются в `ru/NN-hq.webp`.
- `ru/NN.webp` — превью 320 пикселей по ширине для портретных кадров,
  480 пикселей для горизонтальных. Главная загружает эти 14 небольших кадров сразу.
- `ru/NN-medium.webp` — варианты 640/960 пикселей для галерей и первых экранов.
- Все новые варианты — lossless WebP. Промежуточные PNG в проект не сохраняются.
- Маленькая встроенная WebP-копия заполняет рамку во время загрузки.
- Полный оригинал открывается по нажатию на скриншот; начальная загрузка его не запрашивает.
- Во всех языковых версиях используются актуальные скриншоты из текущей публичной
  карточки RuStore. Старые английские материалы не подменяют новый набор при смене языка.

Обновление: `powershell -File tools/fetch-store-screenshots.ps1` (Python 3 + Pillow).
Инструмент заново читает публичные карточки RuStore, исключает изображения
рекомендованных приложений, проверяет весь комплект перед заменой файлов,
пересоздаёт варианты с версиями по хешу содержимого и обновляет разметку.

Проверка: `node --test tools/screenshot-loading.test.mjs tools/story-image-loading.test.mjs`.
