# Графика пробного забега Neon

Ресурсы импортированы из текущего проекта `neon_cyber_wall_kicker` 27.10.2026.
`tools/import-neon-demo-art.py PATH_TO_PROJECT` сохраняет полные оригиналы в
`*-original.webp`, отдельные версии для веб-демо и встроенные превью в `art.js`.
Исходное разрешение и прозрачность оригиналов сохранены; все производные — WebP
lossless. Уменьшенные версии предназначены только для размеров браузерного демо.
Точные пути оригиналов, размеры и границы видимого рисунка находятся в `art.js`.

Герой — нынешние рисованные позы из `assets/ui/comic_menu/hero*.webp`.
Фон — три слоя `assets/backgrounds/comic_worlds/solar_*.webp` с независимым
параллаксом. Монета — изолированная первая ячейка `coin_sheet.webp`, без соседних
кадров. Стены рисуются кодом по `scripts/comic_wall_art.gd`, без загрузки текстур.
Масштаб героя учитывает прозрачные поля; ладони привязаны к поверхности стены.

`neon-current-demo.js` запускается независимо от асинхронного `art.js`: даже до
получения изображений видны стены и контрастный временный силуэт кометы.
Встроенные превью дают настоящие рисунки без дополнительных запросов. Более
чёткие версии подгружаются по одной, только рядом с игровым полем; ошибка картинки
не прерывает игру. Перезапуск и уход со страницы освобождают цикл анимации.

Это короткое браузерное упражнение с фиксированной физикой 60 Гц, тапом,
удержанием и разворотом. Это не полный экспорт Godot: каталоги, все миры и
нативные сервисы остаются в приложении. Проверка: `node tools/check-neon-current.mjs`.

Дополнение: полёт теперь использует шесть исходных нарисованных частей
`assets/player/gameplay_hero_v2/` с точками крепления из
`gameplay_comet_puppet.gd` и движением из `gameplay_hero_motion.gd`.
Набор рисунков фиксируется при отталкивании, без смены силуэта в середине полёта.
Приземление принимает вес вокруг физической точки опоры. Четыре красные мины
перенесены из `Pattern_Start.tscn` вместе с радиусом столкновения 60 и скоростью
вращения 2.2 рад/с; используется актуальный `gameplay_comic/hazard.webp`.
В паузе заморожены физика и анимация; возврат продолжается без скачка времени.
До первого тапа декорация работает на 30 кадрах/с, игрок остаётся на месте.
При reduced-motion декоративное движение останавливается. Движение после
пользовательского ввода остаётся доступным.
