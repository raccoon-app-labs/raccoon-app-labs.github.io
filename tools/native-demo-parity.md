# Сверка браузерных механик с исходниками

Веб-демо воспроизводят выбранный экран/сценарий, а не целое Android-приложение. Данные примера не синхронизируются и не сохраняются. Оригинальная графика используется из исходных проектов.

| Приложение | Исходный экран | Перенесённое поведение и движение |
| --- | --- | --- |
| Волшебные истории | ReaderActivity.kt, activity_reader_clean.xml, StoriesRu.kt / StoriesEn.kt | Первые три страницы Лунного зайчика с соответствующими slide_s1_p1–p3.webp; растворение кадра 240ms из RemoteImageLoader.kt без перемещения/масштабирования, границы перелистывания, избранное; заголовок 14dp/280ms, текст 14dp+6dp/300ms с задержкой 70ms. Предыдущий кадр остаётся до загрузки следующего, быстрые переходы защищены номером поколения. Для чтения используется голос браузера, не семейная аудиозапись. |
| Hanzi Keys | FindKeyBreakdown.kt / FindKeyScreen | Четыре пастельных ответа; ошибка разрешает повтор, верный ответ блокирует варианты и открывает Готово. Появление 500ms, ответ 650ms, поворот ошибки ±5°, увеличение правильного ответа 1.035. Три учебных примера. |
| Hanzi Bloom | BaoBaoApp.kt / ExplodedPartsPanel, StructureDrawing.kt, Motion.kt | Цветные компоненты в собранном состоянии; перемещение ±18→±72dp, scale .42→1, наклон ±3°, цвет 340ms. Пружина damping .68/stiffness1500. Выбор приглушает другую часть до .32 на 220ms и открывает её; фон собирает знак. Узкая веб-версия масштабирует расстояние. Карточки частей содержат лишь базовые данные, не полный справочник. |
| Что едим? | WeekScreen.kt / CompactMealCard / MealEditorSheet | Все 7 дней × 3 приёма; панель выбора блюда, порции, поиск, свой текст, удалить/повторить завтра с подтверждением замены. Продукты объединяются, собственный текст не генерирует ингредиенты. Три блюда/учебные ингредиенты вместо полного каталога. |
| Докупить | FreshDokupitApp.kt / FreshInventoryScreen / FreshShoppingScreen | Докупить сразу переводит в покупки, чекбокс не возвращает товар автоматически: нужно завершить покупки. Метрики, поиск, прогресс; карточка180ms, покупка170ms, появление завершения160ms, конфетти950ms. Без приглашений/синхронизации. |
| Мурополис | GameView.kt / cityObjectHoldDelayMs | Свободное размещение, подтверждение, зажатие760ms для переноса. Клавиатурная адаптация для браузера. Только миниатюра размещения: без экономики, навигации карты и полного мира. |
| Neon Cyber Wall Kicker | Active Main.tscn → iconic/main_learning_loop.gd; Player.tscn → player_visual_clarity → meta_expansion → stabilized → magnet_fixed → player | Нативные единицы 1080×1920, фиксированная физика60Hz; оригинальные wall/stand/flight clean_v3 со scale4/3 и коррекцией поз; classic texture по кривой, затухание при посадке .52s; hold boost .30s/X1050/Y920 плюс thrust1400/1s; perfect .145s ×1.06/1.035; camera lerp .08, разворот и буфер .17s. Pattern_Start + OutskirtsSteps + FirstSignalArc со spread1.2; стены/монеты из текущих ресурсов, charged ×1.36/1.28, шипы, окончание фрагмента45m. CyberBackdropClarity world01, quiet ribbons/phase gates. Это JS-адаптация начального участка, не Godot: нет остальных секторов, магнитных сил, ежедневных режимов, сервисов, звука и полного mesh/shader-паритета. Проверки: tools/check-neon-current.mjs. |

Браузер и Android используют разные рендереры, шрифтовые движки и физические движки. Это не утверждение о побитовом/пиксельном совпадении. Reduced motion отключает декоративное движение, а игровое управление остаётся рабочим. Не добавлять выдуманные функции от имени приложения.
