Перед знакомством

Хорошие вопросы. Понятные ответы.

Можно пользоваться без регистрации?

Да. Личный список доступен локально. Общий доступ подключается для совместного использования.

Как пригласить близкого?

В разделе «Дом» создайте ссылку-приглашение. Новый участник отправит запрос, который подтверждает владелец.

Общий список работает без интернета?

Сохранённые данные доступны локально. Для синхронизации изменений между участниками нужно подключение к интернету.
