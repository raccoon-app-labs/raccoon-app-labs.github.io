# Загрузка изображений на страницах приложений

Проверка 27.10.2026 обнаружила несколько независимых причин задержки:

- Галереи выбирали 640-пиксельные изображения на экранах высокой плотности:
  2–8 МиБ на галерею вместо 0,6–2,4 МиБ для обычных превью.
- Предзагрузка целых галерей и демо конкурировала с первым экраном. Главная
  начинала скачивать все 14 скриншотов сразу.
- Некоторые небольшие иконки и элементы демо использовали крупные оригиналы.
- Внешний CSS Google Fonts находился в блокирующей цепочке стилей.
- В ходе сетевой проверки HTML Neon пришёл за 5,92 с (первый байт 2,70 с),
  а за 15 с загрузки большого скриншота было получено только 196608 байт.
  Это наблюдение для текущего соединения, а не постоянная скорость GitHub Pages.
- Частично полученный WebP мог отображать только верхние строки изображения.

Теперь HTML содержит встроенное маленькое полное превью. Галереи показывают
целую чёткую картинку после `decode()`, а не частично загруженные строки.
`assets/screenshot-loading.js` запрашивает ближайшие изображения с запасом
600 px по вертикали и 200 px по горизонтали, максимум два одновременно;
очередь отдаёт приоритет текущей области просмотра. Дальний конец галереи
подключается по мере горизонтальной прокрутки. Ошибка освобождает очередь и
показывает кнопку повтора. Переключение языка не меняет URL изображений.

В галереях используются обычные lossless-превью, без автоматической загрузки
средних версий по DPR. Полные оригиналы открываются по нажатию на скриншот.
Объём изображений галереи на экране высокой плотности уменьшен на 70–72%.
Новые WebP для иконок, иллюстраций и демо сохраняют альфа-канал; полноразмерные
оригиналы остаются на месте. Уменьшенные производные создаются отдельно и
подключаются только тогда, когда они меньше оригинала. Скрипт:
`python tools/build-display-images.py`. Манифест: `assets/display/manifest.json`.

Manrope хранится локально в `assets/fonts/manrope/`; CSS сохраняет официальные
Unicode-подмножества и веса. Источники — Google Fonts CSS API и репозиторий
`google/fonts/ofl/manrope`; лицензия SIL OFL находится рядом с файлами.

После обновления скриншотов запускайте `tools/update-screenshot-markup.py`,
после изменения иллюстраций — `tools/build-display-images.py`. Обновляйте
версии изменённых JS/CSS и существующие SRI по LF-нормализованному содержимому.
Проверки: `node --test tools/screenshot-loading.test.mjs tools/story-image-loading.test.mjs`
и `node tools/check-neon-current.mjs`. В браузере проверяйте галерею, переход
между слайдами, ошибки, мобильную ширину и нативные демо.

Повреждённый старый `salad.webp` заменён актуальной иллюстрацией овощного супа
из WhatToEatAndroid; название блюда и состав списка покупок обновлены вместе.
