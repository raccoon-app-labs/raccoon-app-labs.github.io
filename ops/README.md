# Основной сайт на VPS

Основной адрес — https://neonwallkicker.ru, www перенаправляется на него.
Сохраняются все пути страниц и ресурсов, языковые версии и приложения.
Сайт статический: базы аккаунтов и платёжные провайдеры не переносятся.

`prepare-vps.mjs` обновляет канонические адреса, версии ресурсов и SRI.
Архивные условия покупок не переписываются. GitHub Pages остаётся
совместимым входом: переход происходит только после HTTPS-проверки нового
сайта, с сохранением пути, query и hash; при ошибке старая страница работает.
При смене origin потребуется повторный вход: sessionStorage разных доменов
не переносится. Сами аккаунты, покупки и подписки остаются на прежних API.

На VPS используется Caddy, каталог `/srv/raccoon-site/releases/<commit>`
и атомарная ссылка `current`. Проверенный сценарий находится в репозитории
enotessa/neon_cyber_wall_kicker, `server/ops/deploy-site.py`, конфигурация —
`server/Caddyfile`. Он скачивает полный архив конкретного коммита, проверяет
API, 59 страниц, каталоги других касс и запрет запросов с посторонним Origin
через временный сервер только на loopback. База не копируется и не меняется;
перед обновлением выполняется штатный зашифрованный backup.

Hanzi RU и Stories используют ограниченные одноимённые маршруты
`/services/hanzi-ru/` и `/services/stories/` того же сайта. Они направляют
запросы на прежние API без cookies, сохраняя авторизацию и адреса провайдера.
DNS-записи MX/TXT, api и почтовых поддоменов не изменяются.

Проверка: `node --test tools/*.test.mjs`.
